# 🍅 Pomodoro Timer

A simple Pomodoro Timer application built using Python and Tkinter.

The Pomodoro Technique helps improve productivity by dividing work into focused sessions followed by short and long breaks.

## 📌 Features

- 25-minute Work Session
- 5-minute Short Break
- 20-minute Long Break
- Automatically switches between Work and Break sessions
- Long break after every 4 work sessions
- Displays completed work sessions using ✔ marks
- Start button to begin the timer
- Reset button to reset the timer
- Tomato-themed timer interface

## 🛠️ Technologies Used

- Python
- Tkinter
- Tkinter Canvas
- Tkinter PhotoImage
